# Qwen3-TTS samples

Generated by `test_tts.py` against the vLLM-Omni OpenAI `/v1/audio/speech`
endpoint. All clips are 24 kHz mono 16-bit WAV. `manifest.json` holds the exact
prompt, parameters, latency and RTF for every clip.

Measured on the RTX PRO 6000 with the conservative deploy configs (each stage
`gpu_memory_utilization` 0.05–0.07, `enforce_eager`), while a 27B vision LLM and
other TTS containers were also resident — mean **RTF ≈ 0.14** (≈7× faster than
real time) for 1.7B, **≈0.12** for 0.6B.

## Regenerate

```bash
# one server per suite (see the compose files); then:
python3 test_tts.py --suite customvoice --base-url http://localhost:12437/v1 --model qwen3-tts-1.7b-customvoice --warmup
python3 test_tts.py --suite voicedesign --base-url http://localhost:12438/v1 --model qwen3-tts-1.7b-voicedesign --warmup
python3 test_tts.py --suite clone       --base-url http://localhost:12439/v1 --model qwen3-tts-1.7b-base \
    --ref-audio samples/customvoice_en_ryan.wav \
    --ref-text "The quick brown fox jumps over the lazy dog, clear as a bell."
```
